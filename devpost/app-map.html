2. Key Code Locations

  • User Input & Context: src/client/components/InputPanel.tsx & ContextChips.tsx
  • API & AI Prompt: src/app/api/analyze/route.ts, src/server/groq.ts, and src/server/prompt.ts
  • Deterministic Rules: src/shared/rules.ts (Quote matching & nextMove stamp selection)
  • Highlight Alignment: src/shared/highlight.ts (Maps quotes to character indices & resolves overlapping lane colors)
  • Report Rendering: src/client/components/ReportView.tsx, PostView.tsx, LaneCard.tsx, and NextMoveStamp.tsx

3. To Change Something, Start Here

  • AI prompt rules or lane definitions: Modify src/server/prompt.ts.
  • Quote validation or stamp recommendation logic: Modify src/shared/rules.ts.
  • Highlight color tokens or paper-card styling: Modify src/app/globals.css.
  • Sample posts data: Modify src/shared/data/samples.ts and run npm run capture:samples.

4. A Practice to Reuse

Decouple AI Outputs from Deterministic Sanitization:

Rather than trusting raw AI outputs directly in the UI, Ghostlisted runs pure deterministic TypeScript rules (validateQuotes and nextMove) on the server before sending data to the browser. This guarantees that hallucinated quotes never reach the user interface.
